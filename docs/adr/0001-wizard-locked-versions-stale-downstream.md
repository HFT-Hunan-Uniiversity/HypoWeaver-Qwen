# 向导式流程：确认即锁定版本，修改上游则下游"需要更新"

研究流程按六个阶段做成向导：未完成的阶段锁定，用户只能沿唯一的主按钮前进，"确认并进入下一阶段"会锁定该阶段的一个版本。修改已确认阶段会产生新版本，下游阶段全部标为"需要更新"，由主按钮"更新下一阶段"带用户依次重做，未受影响的内容预填保留。我们放弃了"自由跳转 + 各页独立保存"的旧模式，以及给熟手的"一键跑到底"和快捷键：目标用户是第一次做研究的人，他们最大的困惑是"该点哪个、看哪个"。代价是熟手多点几下，下游重做也更显式。这个约束会改变后端的数据模型（阶段版本、上游依赖、stale 标记），所以以后很难回退。

## Consequences

- 后端需要按阶段记录版本和 `stale` 状态；前端不能再假设"最新保存即生效"。
- 不再提供单独的"保存"按钮，所有编辑都自动存为草稿。
